# Fun projects

## Function

Use programming to explore personal interests and automate the collection and organisation of useful information.

## Overview

A collection of personal coding projects. It currently contains a Fantasy Premier League tool for bringing player statistics and fixture information together in Excel.

## Contents

Fantasy Premier League — Retrieve player statistics, gameweek points and fixture difficulties, with optional FotMob data, and refresh a formatted Excel worksheet.

## Context and contribution

I developed these tools for personal interests and to extend my practical programming skills.

Developed with assistance from ChatGPT. I defined the requirements, adapted and tested the code, checked outputs for errors, and debugged issues.

## How to use

Open a project folder and follow its README for setup and instructions. For the football tool, install the listed Python packages, configure the workbook path and season, and close the workbook in Excel before running. An internet connection is required to retrieve the data.
